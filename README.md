# 🌸 Flavor Code — Interactive Cooking & Recipe Web Application

Flavor Code is a user-centered, responsive cooking assistant web application designed to reduce cognitive load during meal preparation. It bridges the gap between searching for recipes and cooking in real-time, integrating interactive UI/UX features tailored for home cooks and health-conscious users.

## Key Features & HCI Requirements
- **Interactive Cook Mode:** Full-screen distraction-free view with large fonts, sequential step navigation, tips, step timers, and an ingredients checklist.
- **Dynamic Portion Control:** Real-time automatic scaling of ingredient quantities and nutritional values (Calories, Protein, Carbs, Fat) based on serving size adjustments.
- **Dietary & Category Filtering:** Pill-based filters for quick categorization (Healthy, High-Protein, Vegan, Low-Carb, Desserts, etc.).
- **My Kitchen (Personalization):** Profile dashboard with bookmarking/saving features, recent cooking history, and customizable dietary preferences.
- **Live Search & External Media Integration:** Instant search with autocomplete and embedded tutorials/nutrition articles.

## Tech Stack & Methodology
- **Frontend:** HTML5, CSS3 (Custom CSS Variables, Flexbox/Grid), JavaScript (Vanilla ES6+).
- **UX/HCI Methods:** User Persona Analysis, Requirement Engineering, Usability Goals Evaluation, Cognitive Walkthrough, Prototyping.
